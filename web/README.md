# Marquee Lite

The browser tier of Marquee: a small Vite + TypeScript page (no framework) that runs the same
ritual as the native apps for whatever the browser can decode. You drop a film, the house lights go
down, the academy leader counts 3-2-1 while the file is fingerprinted and its subtitles are found,
and the page tells you plainly when it can't play something.

## Run

```bash
npm ci
npm run dev          # http://localhost:5173 — expects the Worker at http://localhost:8787/api
npm test -- --run    # Vitest (happy-dom, TZ=Asia/Kolkata): engine goldens + components
npm run e2e          # Playwright: chromium, firefox, pixel-7 (Worker mocked with page.route)
npm run lint         # biome ci .
npm run build        # tsc --noEmit && vite build
npm run size         # size-limit: JS ≤ 120 KB gzipped, lazy JASSUB chunks excluded
```

Configuration is public only: `VITE_API_BASE` (default `http://localhost:8787/api`),
`VITE_APP_VERSION`, `VITE_BASE_PATH` (`/marquee/` on Pages), and optionally `VITE_RELEASES_URL`.
On `*.github.io` the Releases link comes from the URL. The OpenSubtitles key lives in the Worker
and is never in a `VITE_*` variable.

## Layout

- `src/engine/` is pure (no DOM, `window` or `fetch`; `api.ts` takes an injected fetch) and holds
  the moviehash, the filename grammar, scoring, the leader state machine, tickets, timecodes, the
  sync rule, SRT→VTT, the capability probe and the Worker client. Each file has a colocated test
  that reproduces the goldens in IMPLEMENTATION-PROMPT §6. `TEST_NAMES.txt` (from
  `npm run test-names`) is the TypeScript side of the Dart parity check.
- `src/ui/` holds the landing, the leader, the film gate, the booth, the No Print card, the ticket
  office and the auditorium. Text is only ever set with `textContent`.
- `src/storage/idb.ts` stores subtitles, offsets and the session in IndexedDB. The JWT is sealed
  with a non-extractable AES-GCM key, and "This session only" keeps it in memory.
- `src/styles/tokens.css` is generated by `scripts/tokens.mjs`, so don't edit it.
  `src/styles/app.css` uses token variables only.
- `scripts/make-icons.mjs` generates `public/icons/*.png` without dependencies.

JASSUB (ASS/SSA) is loaded only through a dynamic `import()` when an `.ass`/`.ssa` file attaches.
It runs single-threaded because Pages can't send COOP/COEP, and it is kept out of the precache.
